IV. Logic load và show ads
1. Logic show ads tại LFO2
- Display priority: 202-high ->  high1 ->  high2 ->  normal
2. Logic reload ads khi user click button chọn ngôn ngữ
- Trigger: user click 1 ngôn ngữ ->  reload 202-high/normal
- Display khi user chọn ngôn ngữ khác: 202-high ->  202-normal
- Reload fail ->  vẫn show ads cũ
3. Logic show inter_splash_2 sau LFO
- Điều kiện: enable_inter_splash_2_screen=true  AND 102-spl-n-inter-high is fill AND not shown
- Priority: high ->  high1
